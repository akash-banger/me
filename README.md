# akashbanger.com

My personal site, public from the first commit. Building in public starts here: projects and essays will land as they're ready.

Built with [Astro](https://astro.build) on a small hand-rolled design system (`src/styles/tokens.css` is the source of truth for every design decision). Deployed on Vercel.

## Develop

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
